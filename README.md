# Инструкция по запуску мессенджера

## Шаг 1: Создайте файлы .env 

Создайте файл `.env` в папке `messenger-backend` и `messenger-vite` и заполните его по шаблону из `.env.example`. Там и пример моих данных в комментариях в .env.example

## Шаг 2: Запустить докер: 

`docker-compose up -d --build`

# Недоработки которые не успел реализовать

- Нету валидации запросов пользователя через socket io. То есть пользвоатель может отправить что угодно с какими угодно полями 

- Когда пользователь отправляет сообщение то оно записывается сразу в БД. Проблема в том что если 1000 пользователей будет отправлять сообщения то БД упадет от перегрузки запросов. Надо размернуть Redis для того чтоб сообщения сначала записывались в него, и когда набирается некоторое количество то пачкой отправлять в БД

- Проблема в том что если много пользователей будет общатся, бекенд может не справится отправлять одновременно сколько сообщений через socket io. Надо отправлять в очередь чтоб оно по мере нагруженности отправлял сообщения 

- Сейчас при получении сообщений, каждое сообщение отправляется отдельным событием на фронт. Надо реализовать чтоб пользователю сообщения отправлялись пачкой, то есть массив новых сообщений. Вот пользователю отправили сообщение, бекенду надо отослать новое сообщение другому пользователю, но он задерживает это и ждет определенное время, например 100ms, и если за это время накопилось сообщений этому пользователю то отправть пачкой 

- Пока нету реаций на сообщения, отправления картинок, видео и пока нельзя отвечать на сообщения
